⚙️ Guide de Configuration

1 Configuration des Types de Tickets

📋 Interface de Configuration des Types

Créez et paramétrez facilement vos différents types de tickets (chèques-repas, bons cadeaux) avec leurs taux de déduction spécifiques.

2 Configuration des Modes de Paiement

💳 Ajout des Nouveaux Modes de Paiement

Intégrez les nouveaux modes de paiement par tickets dans la liste des moyens de paiement disponibles dans votre point de vente.

3 Modes de Paiement du Point de Vente

⚡ Configuration POS Avancée

Liste complète des modes de paiement disponibles. Pour les paiements de type chèques, une fenêtre contextuelle s'affichera lors du clic sur le mode pour enregistrer les informations ou scanner le ticket.

4 Option 1 : Saisie Manuelle des Tickets

✏️ Interface de Saisie Intuitive

Interface permettant la saisie rapide des informations : numéro de ticket, montant, avec calcul automatique et instantané de la déduction appliquée.

5 Option 2 : Scan de Codes-Barres

📱 Mode Scanner Ultra-Rapide

Interface POS optimisée avec mode "Scanner" intégré pour une lecture instantanée des codes-barres.
